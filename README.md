# Personal website

Built with [Astro](https://astro.build) and hosted on GitHub Pages.

- `npm run dev` starts a local preview at http://localhost:4321
- `npm run build` builds the site into `dist/`
- Pushing to `main` deploys it (see `.github/workflows/deploy.yml`)

Pages live in `src/pages/`, and the shared page shell is `src/layouts/Base.astro`.
